---
title: Installation
description: Install Minions Portfolio-manager packages
---

## TypeScript / Node.js

```bash
npm install @minions-portfolio-manager/sdk minions-sdk
```

## Python

```bash
pip install minions-portfolio-manager
```

## CLI

```bash
npm install -g @minions-portfolio-manager/cli
```

## Requirements

- **Node.js** 20 or later
- **Python** 3.11 or later (for Python SDK)
