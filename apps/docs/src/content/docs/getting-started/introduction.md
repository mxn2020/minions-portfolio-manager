# Minions Portfolio-manager

Agent to manage global hierarchies, ecosystems, and projects

## Overview

This project is part of the [Minions ecosystem](https://github.com/mxn2020/minions) and provides:

- **TypeScript SDK** (`@minions-portfolio-manager/sdk`) — Core library for Node.js
- **Python SDK** (`minions-portfolio-manager`) — Python bindings
- **CLI Tool** (`@minions-portfolio-manager/cli`) — Command-line interface
- **Web App** — Interactive playground at [portfolio-manager.minions.wtf](https://portfolio-manager.minions.wtf)
