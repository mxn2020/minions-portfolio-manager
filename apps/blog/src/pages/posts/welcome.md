# Welcome to Minions Portfolio-manager

We're excited to introduce **Minions Portfolio-manager** — Agent to manage global hierarchies, ecosystems, and projects.

## What's Included

- **TypeScript SDK**: `npm install @minions-portfolio-manager/sdk`
- **Python SDK**: `pip install minions-portfolio-manager`
- **CLI**: `npm install -g @minions-portfolio-manager/cli`

Check out the [documentation](https://portfolio-manager.minions.help) for a full guide.
